How it works

Each button shows which lights it changes. Pressing a button cycles all those lights forward.

Easy mode uses two colors. The other modes use green, yellow, and red.

There is no move limit. Solving it in 12 moves is not the same as solving it in 80. The detector will judge you.

Press R to restart, H for home, or Q to give up.
